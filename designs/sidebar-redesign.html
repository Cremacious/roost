What changed
Active state
Solid white pill with red icon + text — maximum contrast, reads immediately. Before: translucent white with low contrast against the red.
Nav grouping
Four logical groups — Home · Household · Personal · System — separated by hairline dividers. Prevents the flat 12-item scroll wall.
Household switcher
Inset dark panel (rgba 0,0,0,0.15) with house icon. Looks like a distinct control, not a plain text chip.
User block
Inset dark card with avatar ring + role sub-label. Sign-out gets a tinted icon button. Feels like a footer, not an afterthought.
Red tone
Subtle vertical gradient (#D42020 → #C01A1A) replaces flat #DC2626. Same red family, slightly richer depth.
Width
180px → 200px. Extra 20px makes labels breathe without feeling bloated. Leaves ample main content area on 1280px screens.
